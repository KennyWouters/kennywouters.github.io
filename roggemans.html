Stagiaire développeur web · .NET / Blazor

Roggemans Development 09/2024 – 12/2024 Stage en entreprise

Après ma formation chez BeCode, un stage de quatre mois pour mettre mes compétences en pratique dans une vraie équipe de développement.

Ce que j'ai fait

  • Développé des applications web en C# / .NET avec Blazor.
  • Conçu et utilisé des bases de données relationnelles (SGBD) pour les applications.
  • Travaillé avec les services cloud Azure.
  • Collaboré avec l'équipe sur des projets communs.

Ce que j'ai appris

  • L'écosystème .NET et la construction d'interfaces par composants avec Blazor.
  • La modélisation des données et l'interrogation d'une base de données.
  • Le déploiement et les services d'une plateforme cloud.
  • Le fonctionnement d'une équipe de développement au quotidien.

Ce stage a aussi renforcé mon intérêt pour les architectures logicielles et la conteneurisation.

Technologies
