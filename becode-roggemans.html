Développeur logiciel / web Full Stack

BeCode → Roggemans Development 03/2024 – 12/2024 Formation + mission en entreprise

Point de départ de ma réorientation vers le développement web : une formation intensive chez BeCode, suivie d'une mise en pratique chez Roggemans Development, où j'ai travaillé sur des applications .NET / Blazor.

Ce que j'ai fait

  • Suivi la formation de développeur web full stack chez BeCode, basée sur l'apprentissage par projets.
  • Développé des applications web en C# / .NET avec Blazor chez Roggemans Development.
  • Conçu et utilisé des bases de données relationnelles (SGBD) pour les applications.
  • Travaillé avec les services cloud Azure.
  • Collaboré en équipe sur des projets communs.

Ce que j'ai appris

  • L'écosystème .NET et la construction d'interfaces par composants avec Blazor.
  • La modélisation des données et l'interrogation d'une base de données.
  • Les bases du cloud, que j'ai consolidées avec la certification AWS Cloud Practitioner.
  • Apprendre en autonomie : chercher dans la documentation, tester, se débloquer seul.
  • Travailler en équipe sur du code : se répartir le travail, s'entraider, relire.
